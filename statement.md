# Project Statement

## Problem Statement
Basic image-processing operations are often implemented separately, making it difficult for a beginner to understand how low-level computer vision techniques affect an image. The project provides one simple interface where multiple Module 1 operations can be demonstrated.

## Scope
The project focuses on low-level image processing. It does not attempt to perform advanced object recognition or 3D reconstruction.

## Target Users
- CSE3010 students
- Beginners learning Computer Vision
- Faculty demonstrating image-processing concepts

## High-Level Features
1. Image upload and grayscale conversion
2. Geometric transformations
3. Image filtering
4. Image enhancement
5. Histogram analysis
6. Fourier Transform visualization
7. Noise simulation and restoration
8. Canny edge detection
